# Demon Tides Archipelago Mod
## Features
- All Chests, Challenges, and Bosses are randomized
- Move Randomizer has been implemented
- Snake form is enabled while in the water irregardless of having the item.

## Set Up Guide
- You can find the AP World file [here](https://github.com/RobertSPratley/DemonTidesAPWorld/releases), use the latest release
- To use our mod you have to use Melon Loader, follow the Melon Loader installation guide [here](https://melonwiki.xyz/#/README)
- Once Melon Loader is installed you need to put the mod into the mods folder of the Demon Tides install, the easiest way to access your install is to click on Demon Tides in the Melon Loader installer and then click the folder icon.
- The you need the mod which you can find [here](https://github.com/estradiol-valerate/DemonTidesAP/releases), use the most recent release and exctarct the contents of DemonTidesAP.zip into your mods folder.
- now that that’s all set up you should be able to launch the game however you normally would.
- once the game has launched and BEFORE you connect to the AP server make a NEW RANDOMIZED save file, DISABLE the TUTORIAL in the settings, and then connect to the AP server, now you can start the game. In the future if you need to close the game using the same save file is completely ok.
